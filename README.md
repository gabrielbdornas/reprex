# README

- Para utilizar este reprex você tem que ter o Poetry na sua máquina.
- Para instalar utilizamos `poetry add dpm`, que apresentou um erro. Então escrevemos [este Issue](https://github.com/splor-mg/dpm/issues/91).
- Leia sobre arquivos [.toml](https://learnxinyminutes.com/toml/).
- Precisamos (não agora) melhorar a documentação do [dpm](https://splor-mg.github.io/dpm/getting_started/).
- Exemplo de códigos Python que estão usando código R - [Painel-Ldo](https://github.com/splor-mg/painel-ldo).
- Após instalar o pacote utilizando `poetry add git+https://github.com/splor-mg/dpm` criamos o arquivo `data.toml` e rodamos o comando `dpm install`.
- O pacote `dpm` foi pensado para simplificar a vida dos usuários dos dados orçamentários. Eles não precisam mais ir no BO buscar informações.
